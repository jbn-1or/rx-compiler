# P2：自有模型、构建器、检查器、文本和 CLI

对应 P2.1–P2.4；规范 §15、§16。已有 `../model_test.cpp`、`../entry_test.cpp`、
`../../run_ir.py`；下面是维护和扩展的断言清单，不要求重写基线。

| 编号 | 操作/输入 | 必须断言 | 层次/状态 |
| --- | --- | --- | --- |
| P2-01 | 空 main、显式 unit main、前后空辅助函数 | internal void 源入口、external i32 机器入口；机器入口只调用源入口后返回 0 | U/I/E；已有；`empty_main.rx` |
| P2-02 | main 非首个函数；用户函数名 `__rx_fn_1` | 按稳定 FunctionId 命名，内部名唯一；不假设 main index | U/I；已有；`internal_names.rx` |
| P2-03 | 手动构造 i32 参数/结果 call，串联两个 call | 签名和结果身份正确；void call 不产生值；不代表源码调用已支持 | U/I；已有 |
| P2-04 | MIN 与全 1 位模式常量 | 保留 32 位值；打印可被 LLVM 22 接受且确定 | U/I；已有 |
| P2-05 | 无插入点、终结后 ret/call、跨模块块、错签名参数/ret | builder 在修改前拒绝；指令/值表/终结符/插入点不变 | U；已有核心覆盖，call-after-ret 需单列 |
| P2-06 | 损坏 ID、名称重复/不安全、缺 terminator、缺函数体、跨函数值 | checker 失败且诊断；打印不泄漏部分文本 | U；已有 |
| P2-07 | 未定义值、先用后定义、重复定义、call 错目标/错类型/错参数数 | 全部拒绝；当前仅本块定义顺序，跨块支配到 P6 | U；已有 |
| P2-08 | artifact 移动，销毁 AST/sema，再打印 | 模块及身份稳定且独立存活；不可复制 | U；已有 |
| P2-09 | 相同源重复生成；两个独立模块内容相同 | 文本相同，不包含模块所有权指针/宿主地址 | U/I；已有 |
| P2-10 | 缺 -o、重复 -o、未知 stage、输入不存在、输出目录不存在 | 参数/I/O 错误退出 2；普通 sema/lowering 错误退出 1 | C；已有 |
| P2-11 | 非法源码；另测有效但当前未实现的非空函数 | 不创建新输出；不截断已有 sentinel；有效程序不得空壳成功 | C；已有；支持范围增长后迁移断言 |
| P2-12 | `--dump-tree` 与 IR 同时使用；`/dev/full` | AST 不混入 `.ll`；写入失败退出 2 | C；已有 |
| P2-13 | 函数未使用但包含非法名称/类型 | 完整 sema 先执行，拒绝并保护旧输出 | S/C；已有 |
| P2-14 | 仅 use、生命周期/常量/未使用结构体声明加空 main | 丢弃语法不进入 IR；声明仍有完整 sema 检查 | S/I；use/生命周期扩展待补 |
| P2-15 | 新构建目录，无 LLVM 开发包/LLVM_DIR | rxcc 可配置构建并输出 `.ll`；不含 LLVM 头或链接 API；外部验证单独报告依赖 | C；干净环境待验 |
| P2-16 | 生成 IR 时 PATH 不提供 llvm-as/opt/Clang | rxcc 本身仍成功；外部 runner 报工具缺失 | C；隔离 PATH 的进程测试待补 |

每次新增类型/指令应成对测试合法构造与非法构造，核对 model → builder → checker → printer。
不得把 P2 的“尚未支持”名单永久作为 P3+ 的期望；未来正例见各阶段清单。
