# P1：持久化语义结果

对应 P1.1–P1.3；规范 §6、§7、§10、§12、§13。
已有 `../../semantic_invariants.cpp` 的所有权、绑定、调用、常量查询测试可复用。
本目录源码种子只做语义接受/拒绝和后续行为回归，不能替代 API 查询断言。

| 编号 | 构造/查询 | 必须断言 | 层次/依赖 |
| --- | --- | --- | --- |
| P1-01 | analyzer/临时 scope 销毁后持有 SemanticResult | 结构体字段、签名、常量仍可查；结果拥有符号而非悬垂 scope 指针 | S；P1.1 |
| P1-02 | move 构造、move 赋值 SemanticResult | 所有 ID 和 AST 键仍指向同一事实；AST 必须保持存活 | S；P1.1 |
| P1-03 | `let x=1; let x=2; let x=x; {let x=x;}` | 每个绑定有独立 LocalId；初始化器绑定旧 x，退出块恢复外层 | S；P1.2；`shadowing.rx` |
| P1-04 | 参数 x 被 `let x=x` 遮蔽，另一个函数同名参数 | 参数/局部 ID 唯一；参数 mut/type 不被遮蔽覆盖 | S；P1.2 |
| P1-05 | 同名结构体与函数，前向调用，用户名类似内部符号 | StructId/FunctionId 不混淆；调用保存目标身份，main 不假设编号 0 | S；P1.2 |
| P1-06 | 四种整数、bool、unit、never 表达式 | 保存最终源类型、place/value 类别、原始字面量位模式；同为 i32 表示仍区分源类型 | S；P1.2 |
| P1-07 | MIN、u32 高位常量、关联常量、常量数组长度 | 消费 sema 已验证的结果，不在 IR 重算或二次推导 | S；P1.2；执行依赖 P4/P7 |
| P1-08 | 普通函数、get/print/println、源 main 调用 | 每类 CallTarget 精确且不同；callee 不被记录成函数值 | S；P1.2 |
| P1-09 | impl 中 Self 字段/构造/关联常量 | 使用所属 StructId；显式类型路径与 Self 解析一致 | S；P1.2；行为依赖 P8 |
| P1-10 | 同一引用表达式在 let/参数/返回位置需不同调整 | 原始表达式事实不变；每条使用位置的调整独立，不互相覆盖 | S；P1.3，具体转换 P5 |
| P1-11 | 三条结果边先得到 &mut T，再遇 &T | 最终 LUB 回填先前边；原始类型仍为 &mut T | S；P6.7，数组 P7.2 |
| P1-12 | 不可达普通类型错误/缺失名称/未使用函数体错误 | sema 检查整个 crate，IR 入口相同拒绝；不测试被排除的不可达可变性错误 | S/C；`unreachable_error.rx` |
| P1-13 | 销毁 SemanticResult 后继续使用已生成模块 | 不再读取 sema/AST；artifact 自有所有权 | U；P2；已有 entry_test |
| P1-14 | 缺少必要事实、拿另一个 AST 的结果进入生成器 | 明确内部错误，不能重查名字后猜测或生成空程序 | S/C；已有异 AST 检查 |
| P1-15 | Vec 索引经字段、Box、引用继续投影 | 记录该次可变访问要求，不能仅由最终元素类型决定 | S；P9 联合验收 |

验收：查询覆盖与源码语义检查分别报告；P5/P6/P9 的事实只在对应能力实现后验收。
